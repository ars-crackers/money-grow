# Financial Money Growth 📕

A swipeable pocket book on **how money works and grows** — built as a single self-contained HTML page. No frameworks, no build step, works offline.

## What's inside
A 11-page book you flip through (swipe, arrows, or keyboard):

1. **Cover**
2. **Contents** — tap any chapter to jump
3. **Compounding & Inflation** — the two forces on every rupee
4. **Saving & Investment** — two ways to hold money
5. **Saving & Investment types** — FD, PPF, gold, SIP, equity (typical India returns)
6. **The Cashflow Quadrant** — E · S · B · I, with examples *(concept from Robert Kiyosaki's Rich Dad's Cashflow Quadrant)*
7. **In focus — my own notes** — the quadrant in my own words
8. **Growth rate chart** — what beats inflation
9. **6-week study plan**
10. **Practice words** — flip-cards + "use it" prompts
11. **Closing** — the Rule of 72

Each sub-topic has a **"+"** to expand, plus custom illustrations for easy understanding.

## How to use
Just open `index.html` in any browser — or view it live on GitHub Pages.

## Tech
- Single `index.html` file (HTML + CSS + vanilla JS)
- Google Fonts (Fraunces, IBM Plex Sans/Mono)
- Inline SVG illustrations — no images to load

## Note
Educational only — **not financial advice**. Return figures are indicative long-term averages for India; always check current rates and your own goals before investing. *Rich Dad Poor Dad* and *Cashflow Quadrant* concepts are credited to Robert Kiyosaki and summarised in my own words.
